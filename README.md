# MyHealthApp2
MyHealthChckApp2

## 📱 食事管理Webアプリ（`docs/`）— スマホ向け

ブラウザだけで動く食事管理アプリです（サーバー不要）。GitHub Pages で公開すると
**https://toshiroadachi.github.io/MyHealthApp2/** で開けます。
初期目標は **1日 2,100 kcal / タンパク質 130 g**（設定で変更可）。

### 公開のしかた（最初の1回だけ）
1. GitHub のリポジトリ画面 → **Settings** → **Pages**
2. 「Build and deployment」の Source を **Deploy from a branch** にする
3. Branch でこのアプリがあるブランチ（`main` に取り込み済みなら `main`）と **`/docs`** を選んで **Save**
4. 1〜2分後に上のURLで開けます

### スマホのホーム画面に追加
- iPhone（Safari）：共有ボタン → **ホーム画面に追加**
- Android（Chrome）：メニュー → **ホーム画面に追加**

アプリのように全画面で起動し、電波がなくても開けます。

### 使い方
- **記録**：食品ボタンを **タップするだけで追加**（間違えたら「取り消す」）。量は ×0.5〜×2、
  食事区分は時刻から自動選択。ボタンはよく食べる順に並びます
- 一覧にない食品は「＋ 手入力」。「マイ食品に登録」で次回からボタンになります（登録数の上限なし。「🔍 食品をさがす」で絞り込み）
- 社食・外食などは「🍱 合計だけ入力」。料理ごとのカロリー・タンパク質を並べて入れると合計して1件で記録します
- 食品ボタンは「✏️ 編集」→ タップで削除（初期の食品も削除可。設定から戻せます）
- 「‹」で前の日に戻って記録・確認、各記録の ✕ で削除
- **履歴**：7/14/30/90日のグラフ（目標ライン付き）と日別合計。日付をタップするとその日の記録へ
- **設定**：目標値の変更、マイ食品の削除、バックアップ（JSON）・CSV出力・復元

> ⚠️ 記録はスマホのブラウザ内に保存されます（端末間で共有はされません）。
> 機種変更やブラウザのデータ削除に備えて、設定から時々バックアップを保存してください。

## 🍚 食事管理アプリ Streamlit版（`diet_app.py`）

スマホでサッと入力・確認できる、カロリーとタンパク質の記録アプリです。
初期目標は **1日 2,100 kcal / タンパク質 130 g**（設定タブで変更可）。

### 使い方
- **記録タブ**：上部に今日の合計・残り・達成度を表示
  - 食品ボタンを **タップするだけで追加**（量は ×0.5〜×2 を選べる）
  - 食事区分（朝・昼・夕・間食）は時刻から自動選択
  - 一覧にない食品は「手入力で追加」。「マイ食品に登録」すると次回からボタンで追加可能
  - 日付を変えれば過去日の記録・確認もできる
- **履歴タブ**：7/14/30/90日のグラフ（目標ライン付き）と日別合計
- **設定タブ**：目標値の変更、マイ食品の編集、CSVでのバックアップ・復元

### 起動
```bash
pip install -r requirements.txt
streamlit run diet_app.py
```
同じWi-Fi内のスマホからは、起動時に表示される `Network URL` にアクセスします。
外出先でも使う場合は [Streamlit Community Cloud](https://streamlit.io/cloud) に
このリポジトリを登録し、メインファイルに `diet_app.py` を指定してください。

> ⚠️ 記録は `diet_log.csv` に保存されます。Streamlit Community Cloud ではアプリの再起動時に
> ファイルが消えることがあるため、設定タブから定期的にCSVをダウンロードしてください（復元も可能）。

※ 食品の栄養値は日本食品標準成分表などをもとにした目安です。
